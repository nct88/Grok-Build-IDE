# Privacy

Grok Build IDE stores its editor profile and Grok conversation metadata locally
in the selected user-data directory and the Grok home directory. Content sent to
Grok is handled by the official Grok CLI and the services configured for that CLI.
Review xAI's current terms and privacy policy before using the agent with
sensitive material.

The IDE does not add a separate project telemetry pipeline. Bundled or installed
extensions, web search, MCP servers, plugins, and other tools may have their own
network behavior and policies.

Session transcripts, exported Markdown, logs, diffs, clipboard images, and file
paths can contain sensitive data. Review and redact them before sharing. Never
commit credentials or authentication files from the Grok home directory.

Security-relevant defaults and the private reporting channel are documented in
[SECURITY.md](../SECURITY.md).
