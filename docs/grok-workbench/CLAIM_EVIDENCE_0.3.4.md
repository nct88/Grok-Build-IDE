## Contradiction resolved during verification

The first runtime assertion searched for the folder name in the CDP target title. The application did open the folder, but the workspace reload removed the original CDP target, so that proxy reported a false failure. The final gate no longer relies on the target title: it directly counts visible Win32 windows belonging to the payload and separately validates the active workspace record. The final artifact passed that expanded gate.
