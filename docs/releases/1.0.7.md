# Grok Build IDE 1.0.7

## Tiếng Việt

Grok Build IDE 1.0.7 nâng cấp nội dung phiên theo Grok CLI 1.0.3 với ba tab Session, Context và Account.

- Hiển thị tiêu đề, phiên bản CLI, phương thức xác thực, Session ID, thư mục làm việc, model/backend, sandbox, số lượt, mức suy luận, chế độ quyền và ACP protocol.
- Context có tổng/input/output/cache/reasoning token, số lần gọi model, thời gian API và chi phí.
- Có thể bấm từng dòng để sao chép hoặc dùng Copy all.
- Token và khóa xác thực không được chuyển sang webview.
- Đã kiểm tra giao diện ở 240px, 390px, 600px và scale 150%, gồm dark/light và trạng thái lỗi account.

## English

Grok Build IDE 1.0.7 upgrades session details to match Grok CLI 1.0.3 with separate Session, Context and Account tabs.

- Shows the title, CLI version, authentication method, Session ID, working directory, model/backend, sandbox, turns, reasoning effort, permission mode and ACP protocol.
- Context includes total/input/output/cache/reasoning tokens, model calls, API time and cost.
- Each row is clickable to copy, with an additional Copy all action.
- Authentication tokens and keys never enter the webview.
- Visual verification covers 240px, 390px and 600px widths, 150% scale, dark/light themes and account-error state.
