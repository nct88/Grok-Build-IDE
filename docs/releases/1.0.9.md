# Grok Build IDE 1.0.9

## Tiếng Việt

Grok Build IDE 1.0.9 hoàn thiện nền tảng session và độ tin cậy của quy trình phát hành.

- History có tìm kiếm, nhóm thời gian, trạng thái phiên đang hoạt động và thao tác tiếp tục/đổi tên/xuất/xóa trực tiếp.
- Usage kết hợp context hiện tại, token tích lũy và thông tin gói tài khoản theo bố cục Desktop.
- Session details bổ sung metadata an toàn từ Grok CLI 1.0.3, nhận diện đúng phiên bản CLI và ACP smoke thật.
- Workspace Trust được bật; reverse-terminal mặc định tắt và chỉ hoạt động trong workspace tin cậy.
- VSIX update kiểm tra SHA-256, cập nhật nguyên tử, giữ extension khác và hỗ trợ rollback.
- Base Code OSS, payload, installer và single-EXE được kiểm tra provenance, install/uninstall và runtime end-to-end.

## English

Grok Build IDE 1.0.9 completes the session experience and hardens the release pipeline.

- History includes search, date grouping, active-session state and direct resume/rename/export/delete actions.
- Usage combines current context, cumulative tokens and account-plan information in the Desktop-style layout.
- Session details expose safe Grok CLI 1.0.3 metadata with accurate CLI detection and a real ACP smoke test.
- Workspace Trust is enabled; reverse terminal is disabled by default and requires a trusted workspace.
- VSIX updates verify SHA-256, apply atomically, preserve unrelated extensions and support rollback.
- Code OSS base, payload, installer and single-EXE pass provenance, install/uninstall and runtime E2E checks.
