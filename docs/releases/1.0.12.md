# Grok Build IDE 1.0.12

## Tiếng Việt

Grok Build IDE 1.0.12 đồng bộ host ACP với Grok CLI 1.0.13 mà không thay thế agent loop của CLI.

- Full access dùng `--permission-mode bypassPermissions`; `dontAsk` giữ nguyên ngữ nghĩa CLI là deny nếu chưa allow-list.
- Auto chỉ tự duyệt tool an toàn; `PreToolUse` có quyết định `ask` luôn hiển thị permission card.
- Có lệnh Command Palette **Grok Build: Trust Folder Hooks** và **Untrust Folder Hooks** để ghi cổng trust của CLI vào `trusted_folders.toml` sau khi người dùng xác nhận.
- Đổi permission mode sẽ reconnect và resume session hiện tại; `session/new` và `session/load` cũng nhận `_meta.permissionMode`.
- ACP `session/cancel` được bọc timeout, và real smoke không còn khóa cứng vào CLI 1.0.3.

## English

Grok Build IDE 1.0.12 aligns its ACP host with Grok CLI 1.0.13 without replacing the CLI agent loop.

- Full access uses `--permission-mode bypassPermissions`; `dontAsk` retains the CLI meaning of deny unless allow-listed.
- Auto only approves safe tools; a `PreToolUse` decision of `ask` always produces a permission card.
- Command Palette commands **Grok Build: Trust Folder Hooks** and **Untrust Folder Hooks** write the CLI trust gate to `trusted_folders.toml` after user confirmation.
- Changing permission mode reconnects and resumes the active session; `session/new` and `session/load` also receive `_meta.permissionMode`.
- ACP `session/cancel` is time-bounded, and the real smoke test no longer hard-codes CLI 1.0.3.
