# Grok Build IDE 1.0.10

## Tiếng Việt

Grok Build IDE 1.0.10 đồng bộ khung chat/session với Grok Build Desktop 0.5.38 và mở kho tiện ích hợp pháp.

- Resume phiên khôi phục tóm tắt suy luận an toàn (`summary_text`), last-turn và recap; không lộ `encrypted_content`.
- `session/new` và `session/load` gửi `_meta.reasoningEffort` theo Grok CLI 1.0.5.
- Composer có menu `/` giống TUI, skills local, nhãn tool đang chuẩn bị, và tiêu đề thought “Thought for …”.
- Kho tiện ích Open VSX trong Extensions view, link `grok-build-ide:extension/publisher.name` và lệnh cài từ URL/`itemName`.
- Các tệp Windows chưa được ký số.

## English

Grok Build IDE 1.0.10 aligns the chat/session surface with Grok Build Desktop 0.5.38 and opens a legal extension gallery.

- Resuming a session restores display-safe reasoning summaries (`summary_text`), last-turn and recap; encrypted payloads stay off the UI.
- `session/new` and `session/load` send `_meta.reasoningEffort` for Grok CLI 1.0.5.
- The composer adds a TUI-style `/` menu, local skills, preparing-tool labels, and “Thought for …” titles.
- The Extensions view uses Open VSX, with `grok-build-ide:extension/publisher.name` links and install-from-URL/`itemName`.
- The Windows artifacts are unsigned.
