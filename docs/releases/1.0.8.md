# Grok Build IDE 1.0.8

## Tiếng Việt

Grok Build IDE 1.0.8 làm lại History và Usage để thông tin phiên rõ ràng, hữu ích và gần với Grok Build Desktop hơn.

- History nằm ngay trong Agent, có tìm kiếm, nhóm theo thời gian và đánh dấu phiên đang hoạt động.
- Có thao tác trực tiếp để tiếp tục, đổi tên, xuất Markdown, xóa, làm mới hoặc tạo hội thoại mới; phiên đang hoạt động được bảo vệ khỏi thao tác xóa.
- Cây History gốc của VS Code có metadata, tooltip và menu thao tác đầy đủ hơn.
- Usage mặc định kết hợp mức dùng context hiện tại, thống kê tích lũy của phiên và thông tin gói tài khoản.
- Metadata kỹ thuật được chuyển sang mục Session details để không lấn át thông tin sử dụng chính.
- Đã kiểm tra tám trạng thái giao diện ở 240px, 390px và 600px, scale 100%/150%, dark/light cùng các trạng thái rỗng và lỗi.

## English

Grok Build IDE 1.0.8 rebuilds History and Usage so session information is clearer, more actionable and closer to Grok Build Desktop.

- History now lives directly in the Agent with search, time grouping and an active-session indicator.
- Direct actions resume, rename, export Markdown, delete, refresh or start a new conversation; the active session is protected from deletion.
- The native VS Code History tree has richer metadata, tooltips and action menus.
- The default Usage view combines current context-window progress, cumulative session statistics and account-plan information.
- Technical metadata moves to Session details so it does not obscure primary usage information.
- Eight visual states cover 240px, 390px and 600px widths, 100%/150% scale, dark/light themes and empty/error states.
