# Grok Build IDE 1.0.11

## Tiếng Việt

Grok Build IDE 1.0.11 đưa skill Grok cục bộ vào workspace IDE, siết process tree khi ngắt agent, và giảm quét Git/watcher trên cây lớn.

- Workspace có `.grok/skills` (`/verify-ui`, `/use-mcp`, `/write-fix-log`, `/run-check`) hiện trong menu `/` của Workbench, cùng rule luôn-nạp và Chrome DevTools MCP.
- Ngắt ACP/CLI/terminal dùng `taskkill /T` trên Windows để không để sót `grok.exe` con.
- Portable profile: `window.restoreWindows=one`, không mở Git ở thư mục cha, tắt submodule, loại `node_modules`/`dist`/`workspaces/req_*` khỏi watcher.
- Các tệp Windows chưa được ký số.

## English

Grok Build IDE 1.0.11 adds local Grok skills to the IDE workspace, kills agent process trees on disconnect, and tightens Git/file-watcher defaults on large trees.

- The workspace ships `.grok/skills` (`/verify-ui`, `/use-mcp`, `/write-fix-log`, `/run-check`) in the Workbench `/` menu, plus always-on rules and Chrome DevTools MCP.
- ACP/CLI/terminal teardown uses Windows `taskkill /T` so grandchild `grok.exe` processes cannot leak.
- Portable profile: `window.restoreWindows=one`, never open Git in parent folders, disable submodule detection, and exclude `node_modules`/`dist`/`workspaces/req_*` from the watcher.
- The Windows artifacts are unsigned.
