# Grok Build IDE product identity

Use these names consistently in source, docs, and GitHub. Do not treat
IDE and Desktop as the same product.

| Field | Grok Build IDE | Grok Build Desktop |
|---|---|---|
| Product full name | **Grok Build IDE** | **Grok Build Desktop** |
| This repository | yes | no — separate product |
| GitHub repository | [`nct88/Grok-Build-IDE`](https://github.com/nct88/Grok-Build-IDE) | [`nct88/Grok-Build-Desktop`](https://github.com/nct88/Grok-Build-Desktop) |
| Clone URL | `https://github.com/nct88/Grok-Build-IDE.git` | `https://github.com/nct88/Grok-Build-Desktop.git` |
| Runtime | Official **Grok CLI** via ACP | Official **Grok CLI** via ACP |
| Shell | Code-OSS + Grok Build Workbench | Electron (`apps/desktop`) — not Code-OSS |
| Windows product name | **Grok Build IDE** | **Grok Build** |
| Windows executable | `Grok Build IDE.exe` | `Grok Build.exe` |
| Default install dir | `%LOCALAPPDATA%\Programs\Grok Build IDE\` | `%LOCALAPPDATA%\Programs\Grok Build\` |

Never write **Grok Build CLI**. The engine is the official **Grok CLI**.

The command **Open Grok Build** launches Grok Build Desktop (`Grok Build.exe`).
