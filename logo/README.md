# Grok Build IDE brand assets

- `source-fluffy-character.png` is the user-supplied pink/blue Fluffy reference.
- `fluffy-grok-master.png` is the approved faceless split white/black Fluffy with inverse “grok” lettering and transparent background.
- `processed/` contains the platform-ready size matrix generated from that master.
- Run `scripts/grok-release/update-brand-assets.ps1` to refresh application, installer, server, extension, Windows, Linux, and macOS branding.
