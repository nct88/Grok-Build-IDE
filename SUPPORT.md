# Grok Build IDE Support

Use [GitHub Issues](https://github.com/nct88/Grok-Build-IDE/issues) for
reproducible bugs and feature requests. Search existing issues before opening a
new one.

For a useful support request, include the IDE version, Grok CLI version,
Windows version, install type, exact steps, and sanitized logs from
**View → Output → Grok Build 1.0**. State whether the problem also occurs in the
Grok Build CLI without the IDE.

Do not post credentials, API keys, private prompts, full session exports, or
proprietary source code. Report suspected vulnerabilities privately as described
in [SECURITY.md](SECURITY.md).

Grok Build IDE is an independent Code - OSS distribution. Issues specific to
Microsoft Visual Studio Code or to the upstream Grok Build CLI may need to be
reported to their respective maintainers after the source of the problem is
confirmed.
